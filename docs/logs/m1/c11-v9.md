# M1-C11 V9: APIs.guru corpus as a candidate maker for LIVE_VERBS

scoreV(row, cfg) is run-c11v.mjs's scorer, imported unmodified. This file
does not score against the corpus directly — it only uses corpus lead-token
stats to PROPOSE new LIVE_VERBS candidates, then scores those proposals on
the labelled rows the normal way. run-c11v.mjs is not modified.

**Admission is judged on camara + holdout1 only.** holdout2 is scored and
printed for every run below, but it is never used to decide anything (D24).
